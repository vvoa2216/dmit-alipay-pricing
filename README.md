## 付完之后：退款、换 IP、续费

> DMIT 的退款条款大致是：服务开通不超过 3 天、虚拟机已用传输量不超过 30GB、同一自然人累计不超过 3 次，可以申请全额退款。

**退款能不能退回支付宝，别靠猜。** 退款一般按原支付渠道处理，但跨境支付的原路退回并不总是即时到账。如果这笔钱对你重要，下单前先开工单问一句「支付宝订单的退款走到哪个渠道、大概多久」，比事后追问省事。

**IP 被墙有换的机制。** 社区里普遍提到的说法是每 15 天可以免费更换一次 IP。这个周期值得记住，因为它是很多人选 DMIT 而不是更便宜商家的原因之一。

**不改套餐，续费价不动。** DMIT 每次换代硬件平台（AS3 → AN4 → AN5）都会调价，但已购产品只要不主动升级、不改计费周期，续费价格就锁定在购买时的水平。老用户的续费账单和新用户的挂牌价，经常不是同一个数字。

## 几个常被问到的问题

**支付宝和 PayPal 的价格一样吗？** 一样。发票金额是同一个美元数字，区别只体现在结算汇率和渠道体验上。

**用支付宝付款会不会影响线路或机器质量？** 不会。付款方式和机房、线路、硬件平台没有任何关系。

**支付宝支付会实时到账吗？** 支付宝这个渠道本身是实时的，付完订单状态马上会变。机器开通速度取决于库存和配置方式，正常情况不需要等很久。

**老用户续费还有优惠吗？** 续费价的锁定机制比优惠码实在——不改套餐、不改周期，续费就按买入时的价格走，这在硬件换代涨价的时候差别不小。

**特价机和正式套餐能一起用优惠码吗？** 特价限量款一般不能。正式套餐有时能叠加活动码，结账页填一下就知道。
